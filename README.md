# Digital Library

## Deskripsi
Project ini merupakan latihan awal mata kuliah Full Stack Web Development.

Project menggunakan Laravel sebagai backend dan MySQL sebagai database.

## Teknologi
- PHP 8.3.12
- Laravel
- MySQL
- Composer
- Git & GitHub
- Laragon

## Menjalankan Project

Jalankan server Laravel dengan perintah:

```bash
php artisan serve
